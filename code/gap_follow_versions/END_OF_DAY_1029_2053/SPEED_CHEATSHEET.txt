SPEED - MAIN KNOBS (best values, ~9.4 s lap on hard floor)
  CORNER_SPEED        2.0   speed the car must be at when it reaches CORNER_BRAKE_POINT.
                            Faster corners: 2.2   Running wide / hitting outer wall: 1.8
  CORNER_BRAKE_POINT  1.5   wall distance [m] where it must be down to CORNER_SPEED.
                            Brakes too early: 1.3   Arrives too fast at corners: 1.8-2.0
  BRAKE_DECEL         2.5   how hard it plans to brake [m/s^2]. Higher = later braking, faster straights.
                            Escapes track / overshoots corners: 2.0. On carpet try 2.8-3.0.
  LATERAL_ACCEL       6.5   corner speed from steering. Slides wide in corners: 5.0. More grip (carpet): 7.0
  MAX_SPEED           4.5   top speed cap [m/s] (VESC limit ~5.0 incl. gain). Rarely reached on short straights.
  MIN_SPEED           1.5   never slower than this while driving. Too slow in tight turns: keep; hitting walls in tight turns: 1.2
  MAX_ACCEL           4.0   how fast the speed target ramps up. 5-6 made it escape the track on hard floor.

SPEED - VESC PUSH (leave unless needed)
  SPEED_COMMAND_GAIN  1.10  multiplies every command (VESC runs ~10% slow). All-around slower: 1.0
  BRAKE_BOOST         1.5   over-commands braking when too fast. Jerky braking: 1.0
  ACCEL_BOOST         0.5   over-commands acceleration when too slow. Wheelspin / twitchy: 0.2

STEERING / SAFETY (only if needed)
  TARGET_DEEP_FRACTION 0.98 aim point. Wobbly / indecisive: 0.92. (Lower = later turn-in.)
  MAX_STEERING_RATE    4.0  steering speed [rad/s]. Twitchy: 3.0
  LOOKAHEAD_MAX        1.5  bigger = calmer on straights, turns later
  DISPARITY_BUFFER     2.5  space kept from wall/obstacle edges. Clipping corners/obstacles: 3.0
  SIDE_CLEARANCE       0.30 blocks turning into something beside the car. Clips obstacles: 0.35

QUICK FIXES
  Escapes track / hits wall after straight -> BRAKE_DECEL 2.0, or CORNER_BRAKE_POINT 1.8
  Slides wide in corners                   -> CORNER_SPEED 1.8 and LATERAL_ACCEL 5.0
  Everything too fast, need safe lap       -> SPEED_COMMAND_GAIN 1.0 and BRAKE_DECEL 2.0
  Too slow, lots of margin                 -> CORNER_SPEED +0.2, then BRAKE_DECEL +0.3
  Car stops ("There is no gap" in log)     -> it is too close to something; move it / DISPARITY_BUFFER 2.0
